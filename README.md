# The Robot Vacuum's Funniest Excuse

A zero-dependency Node 22 program that writes one line — the funniest single-line excuse a robot vacuum gives for missing a spot, in the vacuum's own voice — to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

The program validates the kit's gate before writing: the line is UTF-8 text of 1–120 characters, not only whitespace, and a single line.

Entry for the make.fun bounty [The Robot Vacuum's Funniest Excuse](https://make.fun/bounty/u-eager-stork-81-9647-the-robot-vacuum-s-funniest-9822fbd2).
